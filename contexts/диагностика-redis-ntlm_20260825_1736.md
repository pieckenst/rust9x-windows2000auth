```text
UnableToConnect on localhost:6379

Test-NetConnection localhost -Port 6379
```

или:

```cmd
netstat -ano | findstr :6379
```

Если Redis действительно должен быть локальным, сначала надо добиться, чтобы там реально кто-то слушал порт.

То есть **твой показанный middleware из списка подозреваемых можно убрать**.

Самый ценный следующий кусок кода сейчас — **не `WindowsAuthLoggingMiddleware`, а место, где у тебя подключён `Microsoft.AspNetCore.Authentication.Negotiate` / создаётся `NegotiateAuthentication` и конфигурируется `UseAuthentication()`**. Именно там сидит причина `InvalidToken`.
